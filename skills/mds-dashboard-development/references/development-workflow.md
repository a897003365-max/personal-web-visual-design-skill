# 数据看板开发执行清单

本文件摘取原项目的看板检查清单；分支、提交、发布权限由当前项目规则和本次用户授权决定。

<a id="dashboard-workflow"></a>
## 数据看板开发检查清单

完整要求见[规范正文](dashboard-development-standards.md)。以下按工程闭环组织检查入口；每次任务选择适用条款，并补充与本次变更相关的新条款。

### Plan：界定范围与口径

- [ ] 阅读当前工作区规则、看板规范和相关来源契约，标出本次适用的条款编号。
- [ ] 明确受影响页面、共享组件、接口、文件和交付范围；只读、规范-only 与业务实现任务分别执行。
- [ ] 确认指标来源、粒度、范围、日期、单位、公式及官方区间去重依据，检查历史实现与现行规范的差异。入口：[数据规则](dashboard-development-standards.md#rule-01)、[来源与权限](dashboard-development-standards.md#rule-22)。
- [ ] 确认布局、Radix 颜色语义、Noto Sans SC／Barlow Semi Condensed 字体层级，以及当前模块既有业务顺序。入口：[视觉体系](dashboard-development-standards.md#rule-07)。

### Implement：按适用规范实现

- [ ] 实现限于已明确范围，复用现有组件、配色与字段定义；局部样式不波及其他看板。
- [ ] 按涉及内容检查表格、SKU／灯箱、图表／图例／浮窗、配置、加载与更新逻辑。入口：[表格](dashboard-development-standards.md#rule-10)、[图表](dashboard-development-standards.md#rule-14)、[配置](dashboard-development-standards.md#rule-17)、[加载](dashboard-development-standards.md#rule-18)。
- [ ] 生产、交付的数据图表默认附带数据标签，标签与数据及图例显隐同步；密集时调整布局和标签位置。入口：[必显数据标签](dashboard-development-standards.md#rule-26)。
- [ ] 检查动效、键盘操作、导航壳与窄屏，保持页面及接口权限边界。入口：[动效](dashboard-development-standards.md#rule-20)、[适配](dashboard-development-standards.md#rule-21)、[权限](dashboard-development-standards.md#rule-22)。
- [ ] 注释只解释重点逻辑和必要信息；关键缺失状态就近简短显示，详细口径按需查看。入口：[注释规范](dashboard-development-standards.md#rule-25)。

### Validate：核对数据和真实使用路径

- [ ] 按改动范围执行项目已有检查、构建和回归；业务口径变化同步更新受影响的既有断言。
- [ ] 使用官方来源或独立只读查询核对数据，覆盖相关的缺失、零、负值、零分母、部分覆盖、日期对齐、官方区间人数及 `10000` 换算边界。
- [ ] 验证首次近 7 天、快速切换、排序分页、展开与灯箱、图例全部隐藏与恢复、浮窗边缘与长内容、配置确定／取消／恢复默认、刷新及失败状态中的受影响路径，并核对真实字体加载。
- [ ] 在独立页面与主站导航容器内检查至少 1440px、1024px、390px；长名称、大数值、空态、表格留白、冻结交叉层级、浮层裁切按变更范围验证。
- [ ] 在不悬停的默认状态检查图表数据标签，并核对数值、单位、精度、显隐联动和桌面／窄屏下的遮挡、重叠与裁切。
- [ ] 分开记录静态检查、合成数据、真实来源核对、浏览器模拟和真机结果；结果绑定实际提交或文件快照。入口：[验收标准](dashboard-development-standards.md#rule-23)。

### Review / Fix：独立审查并修复

- [ ] 行为改动按当前项目开发流程进入独立上下文审查，提供需求、适用条款、实际差异及验证证据；纯规范文档自查内容和链接即可。
- [ ] 发现问题后修复、重验受影响范围并复审；未解决项保留证据和影响，不以缩减要求代替完成。

### Recap：交付与规范维护

- [ ] 汇报适用条款的实际符合情况、已验证／未验证范围及剩余问题；健康检查和构建结果不代替真实页面验收。
- [ ] 业务变更继续按当前项目流程与本次授权范围交付；本清单不扩大本次任务授权。
- [ ] 规范-only 修改自查差异、目录、相对链接、编号与 Git 忽略状态，不执行提交、推送或部署。
- [ ] 新规范写入唯一正文，新增条目顺延，修订保留编号；同步更新项目入口、交叉引用及本检查清单，不维护固定条款总数。
- [ ] 当前实现与规范的差异记录在独立的本地审计／待整改文件中；规范正文只保留长期要求。入口：[维护规则](dashboard-development-standards.md#rule-24)。
