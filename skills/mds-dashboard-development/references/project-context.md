# 适用范围与维护来源

本技能源于 MDS／mads.ren 的用户确认规范。原项目的规范正文和开发流程仍在其本地工作区维护；本包是用户于 2026-10-28 明确授权制作、备份至个人私有 GitHub 仓库的可移植快照。

- 完整规则见[规范正文](dashboard-development-standards.md)，不固定条款总数。
- 原规范正文仅将项目入口链接调整到本文件，其各条款内容保持原样。原文“本地维护”针对应用仓库；本次技能包的私有仓库备份有单独授权，不改变以后任务的提交或发布权限。
- [开发流程](development-workflow.md#dashboard-workflow)摘取看板专用检查清单，将原项目特定的流程指代改成“当前项目开发流程”。原仓库个人分支、预览服务器和生产部署的持续授权不作为通用技能权限复制。
- MDS 已接入数据库通知、SSE 与版本检查的机制保存在[更新契约](database/dashboard-live-events.md)。这是 MDS 的现有接口契约，不要求其他项目新增同样架构。
- 项目特定的数据库结构、来源身份、权限和日期覆盖必须在实施时核对实际拥有方；规范与当前事实的差异单独记录。

## 主版本、同步副本与验证

| 内容 | 主版本 | 包内用途与同步条件 |
|---|---|---|
| 看板规则 | MDS 本地 `docs/dashboard-development-standards.md` | 用户确认新规则后按授权更新包内快照；正文不固定总数 |
| 看板执行清单 | MDS 本地 `docs/development-workflow.md` 的看板章节 | 与适用条款一起同步，保留当前项目授权边界 |
| Impeccable | 打包时已安装的 Codex 版本 | 原样附带参考与脚本，更新依赖时重新核验版本、许可和所需路径 |
| anti-defensive-writing | 用户共享技能目录版本 | 打包前核对同名 Codex 副本，避免假定内容相同 |
| 配色、字体 | 固定版本的官方 npm 发布包 | 下载时校验包完整性，分发时保留许可证和文件清单 |

安装后的技能目录是分发副本；新版本通过包更新，不在普通任务中自动改写它。副本校验使用仓库根的 `scripts/validate_package.py` 和 `package-manifest.json`。源文件摘要、打包差异与依赖来源可在清单中追溯，不包含机器凭据或业务行数据。
