# MDS 数据看板开发

将用户确认的业务口径、视觉与交互要求落实到具体看板。当前请求决定任务范围；规范整理、只读审计、设计预览和代码实现分别处理，不能从本技能推导发布或生产写入授权。

## 开始工作

1. 读取当前项目适用的 AGENTS.md、相关模块规则和 Git 状态。确认受影响页面、数据源、文件及交付范围。
2. 读取[规范正文](references/dashboard-development-standards.md)中的适用条款。正文是已确认要求的完整来源，编号可持续增加，不固定总数。
3. 使用[开发检查清单](references/development-workflow.md#dashboard-workflow)组织实施与验收。MDS 特有约束及原文与便携包的关系见[项目上下文](references/project-context.md)。

## 必须保持的业务语义

- 区间人数及其派生指标使用同范围、同区间官方去重数据；缺失不能以逐日累计替代。比率按配对有效分子、分母重算。
- 真实零、缺失、负数和部分覆盖明确区分。筛选后的主值、可比周期值和整页／本页合计保持各自口径。
- 首次进入默认最近有效业务日截止的近 7 个自然日；用户选择后按规范保留状态。
- 原始数值严格大于 10000 才转换为“万”，计算、排序和导出仍用原值。正负向指标的变化文案、百分点与 ROI 倍数差按正文处理。
- 旧实现、历史记录和样张不能覆盖用户当前确认的要求。发现差异先定位证据，不能通过修改口径让页面看起来正常。

## 按任务加载依赖技能

依赖技能与本技能位于同一 `skills/` 层级，完整分工及资源路径见[依赖地图](references/dependencies.md)。

- 调色或视觉实现：读取[Impeccable](../impeccable/SKILL.md)和其 [colorize](../impeccable/reference/colorize.md)、[Operate 模式](../impeccable/reference/operate.md)。字体工作再读 [typeset](../impeccable/reference/typeset.md)；其他流程仅按当前任务需要加载。
- 页面注释、口径提示和交付说明：读取[anti-defensive-writing](../anti-defensive-writing/SKILL.md)，保持业务语言直接、说明克制。
- 优先使用包内已固定的依赖版本。执行 Impeccable 时，以实际同级 `impeccable/` 目录作为其 skill base，命令保持在目标项目工作目录运行；不要照抄某台机器的绝对路径。
- 用户已确认的 Radix 语义色、Noto Sans SC／Barlow Semi Condensed 字体、具体版式及必显数据标签要求优先于依赖技能的通用审美建议。只读或文档任务不启动 UI 实现、初始化项目或安装钩子。

## 视觉与交互

- Radix Colors 提供色板；Teal 改善、Tomato 恶化、Amber 待关注、Slate 中性。调色通过语义变量实现，图表系列色与变化状态色分工明确。
- 字体从包内 Fontsource 资产自托管；按需要加载字重和中文分片。入口与示例见[视觉资产](references/assets.md)，不是对现有页面的自动覆盖脚本。
- 表格、冻结列、排序分页、SKU、灯箱、图例显隐、浮窗、指标配置及过期响应保护按规范正文逐项落实。
- 生产、交付的数据图表必须默认附带数据标签，悬浮提示只作补充；标签格式、密集布局与显隐联动遵循[数据标签规则](references/dashboard-development-standards.md#rule-26)。
- 占比图先验证分母及可加性，再按分项数选择圆饼图或南丁格尔玫瑰图；玫瑰图用面积表达真实比例。
- 说明文字只解释重点逻辑或必要信息；关键缺失状态直接简短显示，详细口径按需展开。

## 验收与维护

- 使用目标项目已有工具链，按变更范围核对数据、执行相关检查，并在真实导航容器中验证交互与至少 1440px、1024px、390px 布局。
- 代码行为变更按项目流程做独立审查；纯规范编辑自查内容、相对链接和维护边界。
- 分开记录代码检查、合成数据、官方／只读数据核对、浏览器模拟及真机结果。构建成功不代表线上行为已生效。
- 若当前项目本地规范比包内快照更新，先使用已确认的新规范并记录版本差异；更新技能包属于单独的维护动作，不在普通看板任务中自动上传。
- 输出改动范围、实际验证和未完成项。只在用户已经授权相应目标时提交、推送或部署。
