# 主版本与同步

个人规范的主版本是本技能仓库中的 `skills/personal-web-visual-design/`，不依赖任何业务网站或项目目录。

| 内容 | 主版本 | 同步条件与验证 |
|---|---|---|
| 网页视觉、数据展示与验收规范 | 本仓库对应 references 文件 | 用户确认新增或修订偏好后同步引用、清单、包版本与文件摘要 |
| 已安装主技能 | 由本仓库分发的安装副本 | 比较文件差异、备份被替换版本，再同步并逐文件核对摘要 |
| Impeccable | 包内固定来源快照 | 更新时核验上游来源、许可、版本和实际脚本能力 |
| anti-defensive-writing | 用户维护的共享技能版本 | 比对本包与目标平台副本，确认差异后再更新，不能假定同名即相同 |
| Radix 与 Fontsource 资源 | 清单记录的固定版本发布包 | 保留许可证、来源完整性信息与文件摘要，验证本地引用和实际加载 |

## 发现路径

- 默认安装器写入 `CODEX_HOME/skills`，未设置时写入当前用户 `.codex/skills`。
- 使用共享技能路径的平台可通过 `--target` 指定 `.agents/skills`；Claude Code 可指定 `.claude/skills`。
- 只更新本次明确的目标路径。技能正文和资源保持一致，平台元数据按宿主能力使用；`agents/openai.yaml` 为 Codex 展示元数据。
- 同一次主版本更新检查当前使用的安装副本；其他平台仅在用户要求同步时更新。旧入口替换时移出发现路径，保留恢复副本。

## 维护流程

新增规则写入最相关的主题，保持已有锚点与含义稳定，更新目录和验收入口；不维护固定条目总数。项目专属的接口、环境、数据计算与发布流程保留在各项目文档。

维护者在仓库根运行 `python scripts/validate_package.py --refresh-manifest`，再运行不带参数的校验。更换依赖时同时更新 `package-manifest.json` 中的来源信息；资源和安装脚本改变时验证实际安装和使用路径。

安装器只安装缺失文件或复用相同版本，遇到内容冲突会停止。更新已安装版本前比对差异并备份，再将确认后的完整技能替换到目标目录，避免残留失效引用。

业务项目只引用本技能并记录自身差异，不复制整份规范。普通网页任务不自动修改技能仓库、上传规范或发布网页。
