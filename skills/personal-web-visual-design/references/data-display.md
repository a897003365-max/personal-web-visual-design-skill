# 数据展示规范

本文件在页面包含指标、表格或数据图表时按需使用。它规定读数与交互的呈现方式；来源、去重、计算公式和权限由目标项目定义。

<a id="values"></a>
## 数值、单位与缺失

- 真实零显示 `0`，负值保留负号，缺失显示 `—` 并按实际情况给出简短原因。部分数据标明“已知合计”及覆盖范围。
- 中文数据页面默认在原始数值严格大于 `10000` 时换算为“万”；等于或小于 `10000` 保留原单位。保留万元、万人、万件等业务单位，不混用 K、M，也不自动切换为“亿”。
- 指标卡、表格、坐标、数据标签和提示采用一致精度与单位，同列小数位一致。百分比、百分点和倍数的差别明确可辨。
- 展示换算不改变原始数据、计算、排序、筛选和导出。样例：`10,000 元 → 10,000 元`，`12,345 元 → 1.23 万元`。
- 只表达已经确认的计算结果；图形如何呈现缺失与异常范围见[坐标规则](#chart-marks)。

<a id="change"></a>
## 变化语义与颜色

| 方向 | 数值增加 | 数值减少 |
|---|---|---|
| 越低越好，如费比、退款率、成本、响应时长 | 上升，Tomato | 下降，Teal |
| 越高越好，如转化率、点击率 | 提升，Teal | 下降，Tomato |
| 无法直接判断好坏 | 增加，Slate | 减少，Slate |

- 状态色与文字共同表达含义；不把所有上涨都表达为改善。
- 比较明确标出对应期间，沿用目标项目确认的比较方式。
- 例如退款率从 10% 到 12% 为“上升 2 个百分点”，转化率同样变化为“提升 2 个百分点”。倍数从 3 到 4 的差是“提升 1.00x”，不写成“提升 1 倍”。
- 持平、缺失和无法比较明确区分；基期不适用时不伪造增幅。

<a id="date"></a>
## 日期筛选

- 需要日期区间的经营或监测页面，首次进入默认近 7 天：以最新有效业务日为截止日，包含截止日的连续 7 个自然日。
- 缺失日期保留在所选区间，不能悄悄缩短为“7 个数据日”。当前项目已明确的业务周期在对应界面清楚标出。
- 手动选择后，内部页签切换和同范围刷新保留选择；独立局部日期标明作用范围。
- 业务日期、数据更新时间和页面读取时间用各自准确名称展示；未来实际数据保持缺失。

<a id="tables"></a>
## 表格布局与留白

- 文字左对齐，数值右对齐，日期、序号、状态居中；末级表头与列内容一致，多级分组表头居中。
- 信息列有足够空间，指标列宽稳定；刷新和排序不使整表跳动。
- 同级行统一高度和内边距，长内容换行保持整行对齐。合计、小计以适度加粗或浅色底区分，严格对齐明细列。
- 表格边缘与内容之间保留统一留白，首末列、表头和最后一行不贴边。桌面左右默认 16px，窄屏不少于 12px，上下留白与容器协调。
- 数值格式遵循[数值与单位](#values)，完整名称可查看。

<a id="table-scroll"></a>
## 长表格冻结与滚动

- 纵向长表固定完整表头，多级表头整组固定；横向长表冻结必要识别列。
- 表头与冻结列交叉处层级正确、底色不透明，内容不重叠、不透出。
- 宽表在自身区域横向滚动，保持列宽和字号可读，避免多层滚动互相干扰。
- 菜单、日期选择器和提示浮窗不被滚动区域裁切。

<a id="table-behavior"></a>
## 排序、分页与合计

- 排序入口及当前升降序清楚可辨。按原始值对完整筛选结果排序后再分页，缺失最后，相同值顺序稳定。
- 底部分页区显示总条数、当前页和每页条数。
- 合计覆盖完整筛选范围；仅统计当前页时明确标为“本页小计”。
- 筛选条件变化回到第一页，同时保留仍适用的排序和列配置。

<a id="row-details"></a>
## 行展开与图片

- 有明细的行可展开／收起，用箭头标示状态；子行通过缩进或浅色背景表达层级，数值列与父表对齐。
- 共同指标沿用一致排序方向；加载中、无数据和失败状态显示在对应展开区域。
- 内容图片遵循[灯箱规范](web-visual-standards.md#images)。图片、链接和按钮的点击不同时触发行展开或选择。

<a id="chart-marks"></a>
## 图形、坐标与真实读数

- 日期轴保留完整区间；缺失断线，真实零位于零，负值保留负向位置；只有一个有效点时显示单点，全部缺失显示空态。
- 绘图保留原始观测，不通过补零、截断数值或补造观测让图形完整。
- 坐标标明指标与单位，直接比较的并排图表使用一致单位和标尺。
- 普通比较柱形和比例条从零开始；瀑布表达累计加减。百分比不自动限定在 0%–100%，固定范围遵循已确认定义，原始值保持可查看。
- 图形和刻度保持可读、无重叠或裁切；绘图区对齐见[布局规范](web-visual-standards.md#hierarchy)，标签布局见[数据标签](#chart-labels)。

<a id="chart-labels"></a>
## 生产数据图表必须附带数据标签

- 所有生产、交付的数据图表必须默认显示数据标签，直接呈现对应数值；坐标刻度、图例和悬浮提示不能代替数据标签，悬浮提示作为补充。
- 标签与柱形、条形、数据点、扇区或瀑布分项关联清楚；占比图显示占比。数值、单位和精度遵循[数值展示](#values)，真实零和负值保留，缺失不生成虚假零值标签。
- 标签清晰可读，不重叠、不遮挡关键图形、不被裁切。数据密集时调整布局、绘图区、标签位置或引导线，不通过直接关闭数据标签解决拥挤。
- 筛选、日期、指标或图例变化时，标签与数据同步更新和显隐。
- 验收必须检查不悬停时的默认显示、标签与实际数值一致，以及桌面和窄屏可读性。

<a id="chart-legend"></a>
## 图例显隐

- 点击图例显示或隐藏对应系列，同一图例关联的本期与对比数据同步处理。
- 曲线、柱形、数据点、标签和浮窗中的对应行同步显隐；非固定坐标轴按可见数据更新范围。
- 隐藏项在图例中明确弱化，再次点击恢复；全部隐藏时显示“已隐藏全部系列”并提供恢复入口。

<a id="chart-tooltip"></a>
## 提示浮窗

- 显示系列名称、实际日期或统计区间、数值、单位；对比数据明确对应期间。
- 多系列顺序稳定，名称左对齐、数值右对齐；本期与同期分栏对齐。
- 避让数据点与视口边缘，不被容器裁切；过长内容可在浮窗内滚动。
- 支持悬停、触屏点击、键盘聚焦查看，并方便关闭；主数值展示遵循[数据标签](#chart-labels)。

<a id="chart-type"></a>
## 图表类型

- 时间变化用趋势图；排名和大小比较优先条形图，长名称采用横向条形图。
- 堆叠只组合可相加的分项，不重复堆叠父级汇总与子项。瀑布清楚表达加减，末列等于所展示分项合计，部分数据明确标注。
- 占比图明确分母，分项应为可比较的互斥构成；有重叠的数据不得画成互斥构成。
- 占比分项达到 4 项及以上使用南丁格尔玫瑰图，1–3 项使用圆饼图，无有效数据展示空态。
- 玫瑰图以扇区面积表达数值比例，不能将数值直接用作半径；数据标签、图例与浮窗表达真实值。
- 不同量纲优先分图；确需双轴时明确轴与系列对应关系，超过两种量纲拆为共享日期轴的上下图。

<a id="config"></a>
## 列与指标配置

- 面板区分“可选”与“已选”，合理分组，字段多时支持搜索；已选项可调整顺序。
- 修改先作为草稿，“确定”应用，“取消”不生效，“恢复默认”经确认后应用。
- 必要识别列始终保留；配置按对应页面保存，刷新和日期切换后保留，新字段不覆盖已有选择。

<a id="states"></a>
## 加载、刷新与错误

- 首次加载使用骨架或明确占位，不先显示虚假零值。
- 切换范围后撤下旧范围结果；过期请求的成功与失败都不能覆盖当前状态。
- 同范围刷新保留有效内容及页签、排序、图例、展开和滚动位置。
- 失败状态给出手动重试；保留上次数据时标明数据时间及刷新失败。采用目标项目现有刷新方式。
