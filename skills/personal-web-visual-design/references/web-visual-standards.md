# 个人网页视觉规范

维护日期：2026-11-05。这里集中维护个人已确认的视觉偏好及可复用的网页设计要求。规范按主题和稳定锚点组织，持续扩展，不固定条目总数。

<a id="direction"></a>
## 方向与适用范围

- 默认风格重视中文阅读、厚实标题、鲜明重点和紧凑清晰的内容；用留白保持呼吸感。
- 页面用途决定结构：产品官网围绕理解与行动，工具界面围绕完成任务，内容页围绕阅读，作品页围绕作品本身。
- 当前用户要求、已确认的品牌和项目设计约束决定最终表达；将个人默认色板、字体和密度映射到该页面，并记录必要差异。
- 表格和图表要求只用于实际存在这些内容的页面。业务计算和数据来源遵循目标项目的定义。

<a id="hierarchy"></a>
## 布局与视觉层级

- 明确页面的主要信息和主要操作，按阅读和使用顺序组织内容。
- 重点通过位置、字号、字重、尺寸和配色共同突出；数值强调色、背景色和明暗对比形成主次。
- 同级模块统一左右边线、标题基线、内边距和间距；并排比较内容保持关键对齐线一致。
- 内容需要时让长表格和复杂图表占满一行，保证文字和数值的阅读空间。
- 同类导航、筛选和状态提示的位置一致；局部改版明确作用范围，样式不波及无关页面。

<a id="color"></a>
## 默认配色与语义颜色

- 默认使用 Radix Colors，调色实施与检查使用 `impeccable / colorize`。先检查现有主题，再将颜色集中映射到语义变量。
- 背景、面板、正文、辅助文字、边框、重点和交互状态各有语义角色。使用所附亮／暗色板，核对实际呈现背景下的对比度。
- Teal 表示改善或成功，Tomato 表示恶化或错误，Amber 表示待关注，Slate 表示中性或无可比结论。
- 重点强调色与状态色分工明确；图表系列和类别颜色保持稳定，不因数值涨跌换色。
- 颜色同时配合文字、符号或形状表达含义。持平、缺失、禁用和无可比结论仍须明确可辨。
- 重点不是给每个模块都加鲜艳颜色；次级信息保持清晰，避免与主要内容争夺注意力。

<a id="typography"></a>
## 字体与数字排版

- 默认中文使用 Noto Sans SC，数字和英文使用 Barlow Semi Condensed。字体来自 Fontsource，由目标网站自托管，按需加载字重和中文分片并保留许可。
- 默认字体层级延续“标题厚实、数字醒目、表格紧凑”的偏好。下表是中文工具和数据界面的默认标尺；官网大标题、长文和作品页按实际阅读距离与内容调整，保持角色一致。

| 角色 | 字体 | 默认字号 | 字重 |
|---|---|---|---|
| 页面标题 | Noto Sans SC | 24px；窄屏 22px | 700 |
| 模块标题 | Noto Sans SC | 16px | 600 |
| 正文 | Noto Sans SC | 14px | 400／500 |
| 指标名称 | Noto Sans SC | 14px | 600 |
| 筛选范围、数值单位 | Noto Sans SC | 13px | 500 |
| 表头 | Noto Sans SC | 12px | 600 |
| 核心指标数值 | Barlow Semi Condensed | 46px | 700 |
| 次级指标数值 | Barlow Semi Condensed | 36px | 600 |
| 表格数值 | Barlow Semi Condensed | 18px | 600 |
| 变化提示中的数值 | Barlow Semi Condensed | 16px | 600 |
| 辅助说明 | Noto Sans SC | 12–13px | 400／500 |

- 对齐或动态变化的数值启用 `font-variant-numeric: tabular-nums`。单位紧邻数值、字号较小并沿基线对齐。
- 长名称省略时提供完整内容的可访问提示；关键名称、单位、正负号完整可见。
- 同类文本保持一致的字号、字重和语义颜色。响应式调整以角色为单位，不单独缩小难以排下的关键内容。
- 在实际页面核验字体文件已加载，并检查图表文字和嵌入页面；CSS 声明字体名不等于实际使用了字体。

<a id="spacing"></a>
## 留白与密度

- 相关内容靠近，不同内容组通过间距分隔；页面、卡片和组件之间形成清楚的空间层级。
- 内容与容器边缘保留留白；同级容器沿用一致的内边距和对齐线。
- 表格的数值化留白与对齐要求见[表格布局](data-display.md#tables)。
- 先调整布局、换行、内容区域或局部滚动来解决拥挤，保持正文、单位和按钮可读。

<a id="controls"></a>
## 控件与反馈

- 主要操作在其作用范围内清晰突出；次级操作、危险操作和禁用状态能明确区分。
- 控件保留真实语义、标签及必要状态反馈；选择与筛选的视觉状态统一按[边框规范](#control-borders)实现。
- 输入项的标签持续可见，错误信息靠近对应输入，提示下一步可执行的动作。
- 浮层跟随触发对象，避开屏幕边缘和滚动裁切；长内容保留可访问的滚动空间。
- 列表展开、图片放大、链接和按钮各执行自己的操作，避免一次点击触发多个不相关行为。

<a id="control-borders"></a>
### 选择与筛选控件的统一边框

本节适用于网站所有页面的选择与筛选控件，包括原生下拉框、自定义选择器／Combobox、搜索框、日期输入与选择触发器、筛选按钮、选择标签、分段选项及其选择面板。以控件用途应用规则，自定义选择器即使用 `button` 实现，也采用输入型控件的状态。新增或修改这些控件时统一遵循本节。

#### 输入型控件

矩形输入框和选择触发器统一使用 `1px solid` 边框、`6px` 圆角与面板底色。面板底色默认映射到 `Slate 1`；边框和阴影按下表映射到共享语义变量。

| 状态 | 边框 | 阴影与反馈 |
|---|---|---|
| 默认 | `Slate 7` | `inset 0 1px 2px rgba(28,32,36,.025), 0 1px 2px rgba(28,32,36,.04)` |
| 悬停 | `Slate 8` | `inset 0 1px 2px rgba(28,32,36,.04), 0 2px 4px rgba(28,32,36,.06)` |
| 聚焦 | `Slate 9` | `inset 0 0 0 1px var(--slate-9), 0 2px 8px rgba(28,32,36,.12)` |
| 禁用 | `Slate 6` | 取消阴影，背景 `Slate 3`、文字 `Slate 11`，禁用光标与交互 |

以上阴影值为亮色基线；暗色主题使用对应语义色板并核验边界与焦点可见性。聚焦内描边只增强视觉，不增加实际边框宽度或改变控件尺寸。边框、背景与阴影的过渡使用 `160ms ease-out`，其余遵循[动效规范](#motion)。

#### 筛选按钮与选项

- 应用、清空等普通操作按钮默认使用 `1px Slate 9` 边框与 `6px` 圆角；悬停保留边框并以 `Slate 3` 背景反馈。输入型选择触发器仍按上表处理。
- 列表选项默认用 `1px transparent` 边框预留空间；需要行间分隔时使用 `Slate 6` 底边。未选中选项悬停使用 `Slate 8` 边框与 `Slate 3` 背景。
- 已选标签、选项和分段筛选统一使用 `Teal 7` 边框、`Teal 3` 背景与 `Teal 12` 文字；已选且悬停时边框加深到 `Teal 8`，保留选中底色与文字。选择面板展开时，触发器边框加深到 `Teal 10`。
- 选中和展开分别由真实状态驱动，例如 `aria-selected`、`aria-pressed`、`aria-expanded`；仅填有值的输入框仍按输入型状态显示。
- 复选框、单选框保留原有勾选标记、尺寸与语义形状，复用上述边框色阶和状态规则；圆形单选框保持圆形。

#### 状态组合与键盘焦点

- 普通 hover 不覆盖聚焦、已选、展开或错误状态；输入型控件同时聚焦和展开时保留展开边框与可见焦点。已选悬停使用上文专用状态；禁用控件停止 hover 和交互反馈，保留可辨认的已选标记。
- 键盘焦点必须清晰可见。输入框使用聚焦描边；按钮、列表选项使用 `2px` 面板色间隔加 `2px Teal 11` 外圈，可用 `0 0 0 2px var(--panel), 0 0 0 4px var(--teal-11)` 实现。外圈叠加于选中／展开／错误状态，不能抹掉这些状态。
- 只有提供等效可见焦点后才移除浏览器默认 outline。强制颜色模式保留系统色边框，以 `2px solid Highlight`、`outline-offset: 2px` 显示焦点，不依赖阴影传达状态。
- 复用共享主题或组件，统一处理原生与自定义控件；通过明确的状态选择器及级联顺序落实优先级，避免通用 `button:hover` 覆盖选择器状态。

#### 选择面板与验收

- 选择面板、日期弹层使用 `1px Slate 7` 外边框、`8px` 圆角和面板底色；工具栏、列间、说明区的分隔线使用 `1px Slate 6`。日期等浮动弹层使用 `0 8px 24px rgba(28,32,36,.15)` 阴影，内嵌面板不强加浮层阴影。
- 验收覆盖默认、悬停、聚焦、禁用、选中、展开，以及“选中＋悬停”“展开＋悬停”“聚焦＋悬停”“禁用＋悬停”和键盘焦点；已有错误态还需检查与焦点叠加。
- 检查状态切换前后尺寸稳定、焦点圈不被裁切、桌面与窄屏可读，以及支持的主题和强制颜色模式。规范更新与页面整改分别验收，已有实现的差异记录在对应项目待整改清单。

<a id="images"></a>
## 图片与灯箱

- 可供查看细节的内容图片点击后打开灯箱，以原比例完整展示并适配屏幕；图标、装饰和明确的导航图片按其本身用途交互。
- 灯箱支持关闭按钮、Esc 和点击遮罩关闭，关闭后恢复原焦点与滚动位置。
- 图片加载中、缺图和失败状态分别表达；容器预留空间，避免加载后挤动相邻内容。
- 图片、标题和辅助说明的关系清楚，图片提供符合内容用途的替代文本。

<a id="motion"></a>
## 动效与键盘

- 普通反馈动效为 150–250ms，非加载动效最长 300ms。动效服务状态切换与层级反馈。
- 指标直接显示最终数值；切换内容或条件时取消过期动效。
- 尊重系统“减少动态效果”设置。
- 核心控件可用键盘操作；选择与筛选的焦点样式见[边框规范](#control-borders)。弹窗支持 Esc，关闭后恢复原焦点。

<a id="responsive"></a>
## 桌面与窄屏

- 至少检查 1440px、1024px、390px 三种宽度，并覆盖项目明确支持的其他尺寸。
- 导航和筛选合理换行，内容列数随空间调整；宽表局部横向滚动，图表适配容器。
- 标题、单位、按钮、日历、灯箱和提示浮窗不遮挡、不裁切、不越出可视区。
- 按实际使用环境检查导航外壳或嵌入容器；独立预览与嵌入使用分别验证。
- 浏览器窄屏模拟与真机验证分别记录。

<a id="copy"></a>
## 注释与说明

- 说明文字只解释重点逻辑和必要信息。使用面向读者的语言，一条说明一个要点，通常一句即可。
- 会影响当前理解或操作的缺失、部分覆盖和失败状态就近简短标明；详细解释放在提示或展开内容中。
- 共用说明集中表达，局部差异就近补充，避免在每张卡和每行内容中重复。
- 技术字段和实现细节留在开发文档，除非这些信息能帮助页面用户做决定。
- 数据标签属于必要数值展示，不属于应删减的解释性注释；遵循[必显数据标签](data-display.md#chart-labels)。
